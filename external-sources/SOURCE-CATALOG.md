# LGFC upstream source catalog

Issue: #2878

The complete source workspace is collected as pinned Git submodules by `.github/workflows/collect-upstream-source.yml`.

## Permissive candidates

- CollectionBuilder — complete digital-collection and exhibit templates
- OpenSeadragon — high-resolution and tiled-image viewer
- PhotoSwipe — responsive gallery and lightbox
- FullCalendar — event calendar and scheduling UI
- Payload CMS — content models, admin, workflow, reusable blocks, preview, and publication
- Payload reusable-content example — shared content blocks and page composition
- Sveltia CMS — Git-backed content administration
- Decap CMS — editorial workflow and Git-backed content management
- React Admin — reusable administration interfaces
- PhotoPrism — media indexing, discovery, metadata, and gallery architecture

## File-level copyleft candidates

- TimelineJS3 — chronological media storytelling

## Reciprocal-license/reference systems

- Omeka S — linked historical resources, media, item sets, sites, and exhibits
- Omeka Classic — items, files, collections, citations, and public-history publishing
- Mukurtu CMS — rights, provenance, protocols, contextual narratives, and access controls
- GiveWP — donation and fundraiser workflows

## Not yet verifiable

- Better Giving — public site describes open-source/self-hostable software, but an authoritative public source repository has not been verified.
- Pages CMS — the specific implementation previously referenced has not been authoritatively identified; do not substitute an unrelated repository.

## Operating rule

Complete source may be inspected and compared. No upstream code enters LGFC runtime code until its file-level license, dependencies, security posture, architecture fit, and adaptation boundary are approved.
